# 벨트 장력계 v2

마이크로 벨트 진동음을 녹음해 FFT 주파수 분석으로 장력(N)을 계산합니다.  
호기별 세션 관리·PDF 보고서·현장 맞춤 노이즈 저감을 지원하는 2.0 버전입니다.

## 원리

1. 마이크가 벨트를 두드리는 소리를 녹음합니다.
2. Web Audio API AnalyserNode가 실시간 FFT를 수행합니다.
3. 지배 주파수 `f`와 벨트 파라미터(단위 질량, 폭, 스팬)로 장력을 계산합니다:

   ```
   T [N] = 4 × m × w × L² × f² × 1e⁻⁹
   ```

   | 기호 | 단위 | 설명 |
   |---|---|---|
   | `m` | g/(m·mm) | 폭 1 mm(또는 리브 1개)당 단위 질량 — 벨트 전체 질량(g/m)이 아님 |
   | `w` | mm (또는 리브 수) | 벨트 폭 |
   | `L` | mm | 스팬 길이 |
   | `f` | Hz | 기본 진동 주파수 |

## 기본주파수 판정 (배음 오검출 방지)

목표 잠금 대역(예상 주파수 ±30%)은 T∝f² 이므로 장력 0.49~1.69배만 담습니다. 크게 느슨한 벨트는 기본파 f0가
대역 밖(아래)에 있고 2f0·3f0 배음만 대역 안에 남아, 예전에는 배음을 기본파로 보고 **OK로 오판**할 수 있었습니다.

- 대역 안 최대 피크 f에 대해 **f/2, f/3 위치(10~5000 Hz 안)** 에 유의미한 국소 피크가 있으면 그것을 기본주파수로 환산(최대 2단계)
  - 조건: 선택 피크 대비 -20 dB 이상, 주변 노이즈 바닥 대비 +12 dB 이상, 보간 주파수 비율 오차 ±3.5% 이내
  - 상태 표시: `기본주파수가 고정 대역 밖 — N차 배음을 기본주파수로 환산`
- **정상 톤 배제**: 60/120 Hz 전원 험·모터음처럼 튕기기 전부터 계속 나던 톤은 기본파 후보에서 빼고(예: 360 Hz 벨트 + 120 Hz 험이
  120 Hz로 오판되던 문제), 대역 최대 피크가 그런 톤이면 검출하지 않음. 벨트가 울리는 동안에는 주변 레벨 학습을 멈춰 느슨한 벨트 환산은 그대로
  - 측정 시작 직후 약 0.5초(FFT 창이 차는 동안)는 주변 소리를 배우는 시간 — 이때 튕긴 첫 타격은 연속 모드에서 한 번 무시될 수 있음
- 피크가 대역 **경계**에 붙으면(진짜 피크가 대역 밖일 수 있음) 신뢰도를 30% 이하로 낮추고 **저장을 막습니다** → 고정 범위를 넓히거나 끄고 재측정
- 충격 수집 구간에서는 대역 안 피크가 노이즈 바닥보다 12 dB 이상 돌출하지 않으면 프레임을 버립니다
- 측정 대상 고정 OFF면 분석 범위 전체를 탐색합니다(예전의 숨은 '예상 ±30%' 대역 제거)
- 임계값 근거는 `app.js` 상단 `SUBHARM_*` 주석 참고. 합성 신호(Blackman 창 AnalyserNode 에뮬레이션, 44.1/48 kHz, FFT 8192~32768,
  60 Hz 험·백색 노이즈)로 정상 벨트 700건 배음 오환산 0건, 느슨한 벨트 200건 NG 판정 200건을 확인했습니다.

## 저장 품질 기준

- **연속 측정 모드**: 5프레임 버퍼가 채워지고 안정적일 때(신뢰도 ≥ 50%)만 저장. 저장 후에는 신호가 0.3초 이상 사라졌다가
  다시 튕겨야 다음 값을 저장할 수 있음(같은 진동으로 여러 회차를 채우는 것 방지). 결과는 이상치를 뺀 안정화 주파수로 계산
- **충격 감지 모드**: 1.5초 수집 결과로 저장(기존과 동일)
- 공통: 경계 피크 결과는 저장 불가

## 주요 기능

- 실시간 FFT 주파수 검출 (10 ~ 5000 Hz), FFT 크기 선택 가능 (8192 / 16384 / 32768)
- 장력 자동 계산 (보정계수 CF 적용) + 목표 장력 게이지 (OK/NG 판정)
- **현장 소음 맞춤 노이즈 저감** — 스펙트럴 서브트랙션 방식
  - **현장 맞춤 학습** 버튼으로 수동 학습 (측정 중 3초간 배경 스펙트럼 누적)
  - 학습 완료 후 배경 스펙트럼을 실시간 차감하여 벨트 주파수 SNR 개선
  - 필터 강도 1~4 선택: 노이즈 제거 강도(alpha)와 충격 감지 임계값(triggerK) 연동
  - 학습 진행 칩(`학습 중 0%` → `학습완료`) 표시
- **측정 모드 전환** (측정 보조 패널에서 토글)
  - **연속 측정 모드** (기본값 · 구 V1 방식): 충격 감지 없이 신호 검출 즉시 주파수→장력 실시간 업데이트
  - **적응형 충격 감지 모드**: 주변 RMS EMA 기반 동적 임계값(`ambientRms × triggerK`)으로 벨트 충격을 감지한 후 1.5s 구간 분석
- **목표 주파수 잠금** (기본값 ON): 예상 주파수 ±% 대역만 탐색하여 오측정 방지
- **주파수 스펙트럼**: 10–5000 Hz 실시간 FFT 스펙트럼 표시 (토글)
- 측정 플로우 모드: 호기별 세션·벨트 ID(ID1~ID6)·회차 관리 + 세션 진행 표시
- 단순 모드: 직접 저장 + 단순 CSV
- 프리셋: 구동모듈 벨트(170 N ±20% · 2.8 g/(m·mm)) / 리프팅 벨트(500 N ±10% · 4.2 g/(m·mm))
- 새 호기의 슬롯 형상(Mass·Width·Span·CF)은 **벨트 타입별**로 기억된 값 사용 (구동/리프팅 형상이 섞이지 않음)
- 측정 기록 CSV / PDF 보고서 내보내기 (CSV는 UTF-8 BOM·따옴표 이스케이프·수식 주입 방어, jsPDF는 저장소 내 `assets/vendor` 로컬 파일)
- 타이밍 가이드 (사인파 주기 3/4/5초 선택) + 파형 시각화 — 적응형 충격 감지 ON일 때만 동작
- 화면이 백그라운드로 가면 측정을 중지하고(숨은 탭은 분석이 멈춤), 돌아오면 안내
- 모바일 최적화: sticky 상단바, fixed 하단 액션 버튼, 현재 단계만 표시

## 화면 구성 (Step 흐름)

| Step | 카드 | 내용 |
|---|---|---|
| 1 | 호기 설정 | 벨트 선택, 호기 번호 입력(PARKIE : ## 호기), 대기열 미리보기 |
| 2 | 실시간 분석 | 보정 후 장력(N·kgf·게이지·판정) + 주파수 통계 + Confidence + 신호강도 |
| 4 | 보고서·세션 진행 | 호기별 측정 결과 카드, CSV·PDF 내보내기 (항상 표시) |

> Step 2 카드에 보정 후 장력과 실시간 분석이 통합되어 있습니다.

## 노이즈 저감 상세

### 학습 흐름

```
노이즈 저감 ON
  → 필터 강도 선택 + "현장 맞춤 학습" 버튼 표시

측정 시작 후 "현장 맞춤 학습" 버튼 클릭
  → 칩: "학습 중 0%"
  → 벨트 충격 없는 구간에서 현장 배경 스펙트럼 EMA 누적
  → 충격 발생 시 타이머 일시 정지 (여진 오염 방지, 충격 후 2500ms 쿨다운)

3초 누적 완료
  → 칩: "학습완료"
  → 이후 배경 스펙트럼 실시간 차감 + 느린 드리프트 추적 (beta=0.92)
```

### EMA 파라미터

| 상태 | beta | 설명 |
|---|---|---|
| 학습 중 | 0.60 | 빠른 수렴 (신규 데이터 40% 반영) |
| 학습 완료 후 | 0.92 | 느린 드리프트 추적 (신규 8%) |

### filterStrength 연동

| 강도 | alpha (노이즈 차감) | triggerK (충격 임계 배수) | 용도 |
|---|---|---|---|
| 1 약 | 1.0 | 2.5 | 청정 환경 |
| 2 중 | 1.5 | 4.0 | 일반 환경 (기본값) |
| 3 강 | 2.5 | 6.0 | 소음 환경·모바일 |
| 4 최강 | 3.5 | 8.0 | 고소음·모바일 |

### Confidence 계산

노이즈 저감 학습 완료 후, Confidence SNR 계산에 학습된 프로파일을 noise floor로 사용합니다.  
(원본 raw 스펙트럼 사용 시 배경 소음이 포함되어 SNR이 과소평가되는 문제 수정)

## 파라미터

| 상수 | 값 | 설명 |
|---|---|---|
| `MIN_FREQ` | 10 Hz | 탐색 하한 주파수 |
| `MAX_FREQ` | 5000 Hz | 탐색 상한 주파수 |
| `BROADBAND_RATIO` | 0.45 | 광대역 판정 비율 |
| `PROMINENCE_DB` | 9 dB | 연속 모드 유효 피크의 대역 평균 대비 최소 돌출도 |
| `SUBHARM_MIN_REL_DB` | -20 dB | 기본파 후보(f/2, f/3)의 선택 피크 대비 최소 레벨 |
| `SUBHARM_MIN_PROM_DB` | 12 dB | 기본파 후보의 노이즈 바닥 대비 최소 돌출도 |
| `PEAK_MIN_PROM_DB` | 12 dB | 충격 수집 프레임 피크의 노이즈 바닥 대비 최소 돌출도 |
| `SUBHARM_MIN_RISE_DB` | 6 dB | 기본파 후보·대역 피크가 주변 레벨보다 커야 하는 최소량(정상 톤 배제) |
| `AMBIENT_RISE_S` / `AMBIENT_FALL_S` | 4 s / 0.15 s | 주변 레벨 추적 상승·하강 시정수(조용한 프레임에서만) |
| `AMBIENT_WARMUP_MARGIN_S` | 0.2 s | 시작 직후 무조건 학습 시간 = FFT 창 채움 + 이 값 |
| `EDGE_CONF_CAP` | 30 | 경계 피크 신뢰도 상한(저장 불가) |
| `LIVE_SAVE_MIN_CONF` | 50 | 연속 모드 저장 최소 신뢰도 |
| `REARM_QUIET_MS` | 300 ms | 연속 모드 저장 후 다음 측정을 받기 위한 무신호 시간 |
| `LEARN_DURATION_MS` | 3000 ms | 노이즈 프로파일 학습 필요 시간 |
| `G` | 9.80665 | 중력 가속도 (m/s²) |

## 데이터 저장

측정 기록은 `localStorage['beltTension_v1']`에 JSON으로 저장됩니다. (2.0 전용 — 1.0은 `beltTension_classic_v1`을 별도로 사용)

| 필드 | 내용 |
|---|---|
| `version` | 1 |
| `flowEnabled` | 측정 플로우 ON/OFF |
| `robots` | 호기 배열 `{id, unit, createdAt, startedAt, completedAt, slots:[{key, type, label, targetN, tolPct, mass, width, span, cf, measCount, values:[{freq, corrN, kgf, rawN, conf, time, judge}], average, avgJudge, completedAt}]}` |
| `simpleHistory` | 단순 모드 기록 `{time, freq, corrN, rawN, kgf, conf, mass, width, span, cf, targetN, tolPct, judge}` |
| `filterStrength` | 노이즈 필터 강도 1~4 |
| `adaptiveTrigger` | 적응형 충격 감지 ON/OFF |
| `beltGeom` | 벨트 타입별 형상 기억 `{drive:{mass,width,span,cf}, lifting:{…}}` (2026-10-18 추가) |

- 날짜는 **ISO 문자열**로 저장됩니다(`JSON.stringify`가 `Date.toJSON()`을 먼저 호출). 복원 시 `createdAt`·`startedAt`·`completedAt`·`time` 필드를 `Date`로 되돌립니다.
- 복원 시 구조를 검증해 알 수 없는 벨트 ID·숫자가 아닌 측정값은 버리고, 아직 측정하지 않은 슬롯의 형상은 해당 타입 형상으로 재설정합니다.
- 저장이 실패하면(용량 초과·차단) 토스트로 안내합니다.
