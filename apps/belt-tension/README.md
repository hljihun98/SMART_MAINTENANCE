# 벨트 장력계 v1

마이크로 벨트 진동음을 녹음해 FFT 주파수 분석으로 장력(N)을 계산합니다.
단일 HTML 파일(`index.html` 안에 CSS·JS 인라인)로 구성된 1.0 버전입니다. 다중 로봇 관리·PDF 출력이 필요하면 [벨트 장력계 2.0](../belt-tension-2.0/)을 사용하세요.

## 원리

1. 마이크가 벨트를 두드리는 소리를 녹음합니다.
2. Web Audio API AnalyserNode가 실시간 FFT를 수행합니다.
3. 지배 주파수 `f`와 벨트 파라미터(단위 질량, 폭, 스팬)로 장력을 계산합니다:

   ```
   T [N] = 4 × m × w × L² × f² × 1e⁻⁹
   ```

   | 기호 | 단위 | 설명 |
   |---|---|---|
   | `m` | g/(m·mm) | 폭 1 mm(또는 리브 1개)당 단위 질량 — 벨트 전체 질량(g/m)이 아님 |
   | `w` | mm (또는 리브 수) | 벨트 폭 |
   | `L` | mm | 스팬 길이 |
   | `f` | Hz | 기본 진동 주파수 |

## 주요 기능

- 실시간 FFT 주파수 검출 (10 ~ 5000 Hz)
- 장력 자동 계산 (보정계수 CF 적용)
- 목표 장력 게이지 (허용 오차 시각화, OK/NG 판정)
- 노이즈 저감 필터 (스펙트럴 서브트랙션)
- 목표 주파수 잠금 모드
- **배음 오검출 방지**: 탐색 대역 안 피크의 f/2, f/3 위치에 유의미한 피크가 있으면 그것을 기본주파수로 환산
  (크게 느슨한 벨트의 2·3차 배음이 대역 안에 들어와 OK로 오판되는 문제 방지). 피크가 대역 경계에 붙으면 신뢰도를 낮추고 저장을 막습니다.
- **정상 톤 배제** (2026-10-20, 2.0과 동일): 튕기기 전부터 계속 나던 60/120 Hz 험·모터음은 기본파 후보·검출 피크에서 제외
  (예: 360 Hz 벨트 + 120 Hz 험이 120 Hz로 오판되던 문제). 측정 시작 직후 약 0.5초는 주변 소리를 배우는 시간
- 예상 주파수 **계산** 버튼은 목표 장력·Mass·Width·Span으로 역산합니다(예전 k/Span 계산과 k 입력칸은 실제 벨트와 무관한 10 Hz대 값을 넣어 제거)
- 측정값 **고정(HOLD)** 중에는 새 튕김(충격 수집)이 결과를 덮어쓰지 않습니다
- 프리셋: 리프팅 벨트(500 N ±10%) / 구동모듈 벨트(170 N ±20%)
- 측정 기록 누적·브라우저 저장 및 CSV 내보내기

## 파라미터

| 상수 | 값 | 설명 |
|---|---|---|
| `MIN_FREQ` | 10 Hz | 탐색 하한 주파수 |
| `MAX_FREQ` | 5000 Hz | 탐색 상한 주파수 |
| `BUF_SIZE` | 5 | 이동 평균 버퍼 크기 |
| `OUTLIER_TOL` | 0.12 | 이상치 허용 비율 |
| `BROADBAND_RATIO` | 0.45 | 광대역 판정 비율 |
| `SUBHARM_MIN_REL_DB` | -20 dB | 기본파 후보의 선택 피크 대비 최소 레벨 |
| `SUBHARM_MIN_PROM_DB` | 12 dB | 기본파 후보의 노이즈 바닥 대비 최소 돌출도 |
| `SUBHARM_MIN_RISE_DB` | 6 dB | 기본파 후보·검출 피크가 주변 레벨보다 커야 하는 최소량(정상 톤 배제) |
| `G` | 9.80665 | 중력 가속도 (m/s²) |

## 저장 기준

충격 감지 후 분석 결과가 **Confidence ≥ 90%, 주파수 변동률 ≤ 3%**일 때만 저장됩니다.
같은 결과는 한 번만 저장되며, 피크가 탐색 대역 경계에 있으면 저장되지 않습니다.

## 데이터 저장

측정 기록은 `localStorage['beltTension_classic_v1']`에 JSON으로 저장되어 새로고침 후에도 복원됩니다.
(2.0의 `beltTension_v1`과 스키마가 달라 별도 키를 사용합니다.)

```json
{
  "version": 1,
  "records": [
    { "time": "2026-10-18T03:00:00.000Z", "mass": 4.2, "width": 35, "span": 147, "cf": 1,
      "freq": 198.4, "targetN": 500, "tolPct": 10, "rawN": 500.1, "corrN": 500.1, "kgf": 51.0,
      "confidence": 95, "rangePercent": 1.2, "subN": 1 }
  ]
}
```

- `time`은 ISO 문자열, 목표 미입력 시 `targetN`/`tolPct`는 `null`
- `subN` = 검출 피크가 기본주파수의 몇 배 배음이었는지(1 = 기본파 그대로)
