### 선택 (효과 작음)

- **ROBOSTOCK `flattenTree` (`bom.js`)**: O(n²) → `parentPartNo`별 Map. 부품 수백 개 이상일 때만 의미 있음(1,040개 189ms).
- **ROBOSTOCK 납기 역산 로직 4벌 통합** (`labor.js`, `technician.js` 3곳): 서로 어긋날 위험 제거 목적.
- **ROBOSTOCK 썸네일 지연 로드** (`images.js` `hydrate`): IntersectionObserver, 캐시 상한. 위 `rendAll` 축소 후에도 필요할 때.
- **센서 보고서 `preloadPhotoUrls`**: 현재 단계 사진만 objectURL 생성(시작 약 75% 감소).
- **Torque Tak! `_probe` 결과 메모**: compute 비용 절반. 100만 케이스 비교로 결과 동일 증명됨. 브라우저 체감은 작음.
- **Torque Tak! `MEAS_PRED`**: 사내 시험 대조를 처음 열 때 계산(시작 3~6ms).
- **벨트 2.0 DOM 쓰기 생략**: `setStatus`, 연속 모드 `updateResult`에서 같은 값이면 쓰지 않기(0.3~1ms).
- **벨트 2.0 jsPDF 지연 로드**: 시작은 빨라지지만 PDF 첫 클릭 대기·iOS 팝업 순서 주의.
- **죽은 코드 정리**: 벨트 2.0 `style.css` 미사용 클래스 33개(`unit-edit-*`, `next-robot-*`, `history-toolbar`, `.estimate-input .btn` 등), 없는 `#fs3` 참조 3곳.

### 하지 않기로 한 것 (출력이 바뀜)

- 센서 보고서 PDF 사진 처리 시간 단축: 생성 시간의 75~80%가 사진 리샘플링·인코딩이라, 줄이려면 PDF 사진 결과가 바뀝니다.
- 벨트 장력계 FFT 크기 축소, 프레임 건너뛰기, 스무딩 변경: 측정값이 바뀝니다.
- ROBOSTOCK 2초 자동 저장의 변경 플래그화: 효과 작고 저장 누락 위험.
- Torque Tak! 코드 축소(minify): 빌드가 없고 주석이 규칙.
- 벨트 1.0·2.0 중복 분석 코드(약 450줄) 공용화: 1.0이 이전 버전이라 보류.

## 2. 낮음 등급 오류

### 포털
- **사진 DB 삭제와 용량 측정 경합** — `index.html` `sumIdb()`. DB 존재 확인 직후 다른 탭이 삭제하면 `indexedDB.open()`이 저장소 없는 빈 DB를 만들어 ROBOSTOCK 사진 첨부가 실패할 수 있음(강제 재현만 됨). 수정: `req.onupgradeneeded = function(){ req.transaction.abort(); };` 한 줄.

### 센서 보고서
- **포털 삭제 뒤 열려 있던 탭이 빈 사진 DB를 다시 만듦** — `openPhotoDb`, `onversionchange`. 수정: 삭제 감지 시 플래그를 세우고 다시 열지 않기.
- **손상 데이터 + 백업 공간 없음에서 [새로 시작] 시 원본 사진 정리됨** — `handleCorruptState`, `collectGarbagePhotos`. 수정: 원본의 사진 id를 작은 키에 남겨 GC에서 제외.
- **사진 처리 중 초기화하면 그 사진이 새 상태에 되살아남** — `upload` → 초기화 세대 토큰으로 버리기.
- **IndexedDB를 못 여는 세션(메모리 모드) 경고가 "삭제됨"으로 안내** — 문구와 × 버튼 처리.
- **사진 처리 후 메모 입력 포커스·모바일 키보드가 닫힘** — 전체 `render()` 때문(위 최적화로 함께 해결).
- **예전 데이터의 호기 상태가 '직접 선택'으로 옮겨져 자동 설정이 내리지 못함** — 마이그레이션 시 `statusAuto=true`.
- **사진 × 삭제에 확인창 없음** — 확인창 또는 되돌리기 토스트.
- **schema 5 이상 데이터를 옛 형식으로 덮어씀** — `d.schema > SCHEMA_VERSION`이면 읽기 전용.

### 벨트 장력계
- **1.0 자동 종료 뒤 '고정 해제' 버튼이 눌러도 동작 안 함** — `belt-tension/index.html` `toggleHold`. 수정: 자동 종료 시 `btnHold.disabled=true`.
- **2.0 화면 회전 시 파형 캔버스 크기 미갱신** — `resize` 리스너에 `setupWaveformCanvas()` 추가.
- **2.0 측정 시작 시 일시중지 호기보다 대기 호기를 먼저 고름** — `initRobotIfNeeded`. 의도 확인 후 재개 우선으로.
- **2.0 마이크 권한 대기 중(`starting`) 삭제·취소·모드 전환이 시작을 막지 못함** — 조건을 `measuring||starting`으로.
- **2.0 호기 대기열 미리보기가 갱신되지 않음** — `clearHistory`·취소·시작 경로에서 `renderRobotQueuePreview()`.
- **2.0 저장 시 장력·형상값이 유한한지 검사 안 함** — `isFinite` 검사.
- **CSV 자리표시 '-'·'--'에 아포스트로피가 붙음** — 수식 방어 정규식에서 `/^-+$/` 제외.
- **2.0 안내 문구가 동작과 다름** — 적응형 OFF 설명, 도움말 "충격 감지 후 0.5초".
- **느슨한 벨트가 울림 끝부분에서 2f0로 읽혀 '저장 가능 OK' 프레임이 생김** — 감지 하한 아래로 f0가 먼저 사라지는 문제. 측정 로직이라 별도 검토 필요.

### Torque Tak!
- **"탁!"이 위 라벨과 겹침** — 길이 슬라이더가 켜져 있고 적합 기준이 트랙 왼쪽에 있을 때(`M8-200` 등). `.snap` 위치 조정.
- **트랙을 한 번 눌러 기준을 넘으면 틱/탁이 없음** — `pointerdown`의 `set(e.clientX,false)`. 의도 확인 후 `true`.
- **"틱!" 직후 "탁!"이면 썸 강조가 일찍 꺼짐** — `pop()`의 타이머 id 저장 후 clearTimeout.
- **볼트 길이 200mm 초과 시 길이 슬라이더가 볼트를 줄임** — `lenMax`, `BOLT_LEN`.
- **SEMS 8.8 M18 이상에서 잘못된 공급 등급 경고** — `clsOf(...).su`와 비교.
- **저두의 파단 위치를 "볼트 목 파단"으로 표시** — `breakMode`에 `H.socket` 반영.
- **정확히 6산일 때 부동소수점으로 "주의"** — 나사산 수 비교에 허용오차.
- **길이가 토크를 제한하는데 칩에 "토크 무관"** — `R.reachLimited`일 때 문구 변경.
- **README·화면 하단의 뽑힘 식 표기가 코드와 다름** — `min(0.875πd·τ_모재, 0.75πD₁·0.6σu_볼트)·Le·0.65`.
- **사양에 "mm"를 붙이면 길이가 사라짐**(`M5 12mm`) — 파싱 정규식.
- **하중 "미입력" 선택 후에도 하중 칸 오류 문구가 남음** — `numErr("loadErr",true)`.

### ROBOSTOCK
- **실제 공수 모달을 다시 열면 이전 시간·메모가 남음** — `openMo('mo-actual')`에서 초기화.
- **사진 처리 중 입고 모달을 닫으면 사진이 남아 다음 입고에 붙을 수 있음** — `addPh` 세대 값 확인.
- **대시보드 목표 대수 입력 중 포커스가 빠짐** — `setGoal`을 onchange로.
- **다른 탭이 2초 안에 저장하면 이 탭의 방금 거래가 롤백됨** — 변경 직후 즉시 저장 또는 추가 전용 배열 병합.

- **새로고침 후 관리자 로그인 시 미답변 문의 알림 점이 안 보임** — `initApp`·`go('admin')`에서 `updateInqDots()`.
- **대시보드 '금일 작업 공정' 체크가 다른 작업 때마다 풀림** — 체크 상태 보관.
